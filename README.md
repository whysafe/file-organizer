# Сортировщик файлов

Утилита командной строки раскладывает файлы в папке (например, «Загрузки») по категориям: документы, изображения, видео, аудио, архивы, программы, код. Ничего не перезаписывает и умеет отменять последний запуск.

## Возможности

- 7 категорий по расширению и папка «Другое» для остальных файлов
- `--dry-run`: показать план (первые 30 переносов и итог по категориям), ничего не трогая
- Ничего не перезаписывает: при совпадении имён добавляет « (2)», « (3)»
- `--dedupe`: точные копии (по SHA-256) уходят в папку «Дубликаты», с учётом уже разложенных файлов
- `--by-date`: внутри категорий раскладывает по месяцам (`ГГГГ-ММ` по дате изменения)
- `--undo`: отменяет последний запуск по журналу и удаляет опустевшие папки
- Скрытые файлы и вложенные папки не трогает, разбирает только корень
- Только стандартная библиотека Python, работает на Windows, macOS и Linux

## Стек

Python 3.10+ (`pathlib`, `shutil`, `hashlib`, `argparse`, `json`), pytest для тестов.

## Как запустить

```bash
python organizer.py ~/Downloads --dry-run
python organizer.py ~/Downloads --dedupe --by-date
python organizer.py ~/Downloads --undo
```

На Windows путь пишется так: `python organizer.py "C:\Users\Имя\Downloads" --dry-run`

Тесты:

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
python -m pytest -v
```

Тесты запускаются в GitHub Actions (`.github/workflows/tests.yml`) на Python 3.11 и 3.12.

## Настройка

Категории и расширения задаются в словаре `CATEGORIES` в начале `organizer.py`. Там же названия папок «Другое» и «Дубликаты» и имя файла журнала `.organizer-log.json`.

## Структура проекта

```
organizer.py              # план переносов, применение, журнал, отмена, CLI
tests/test_organizer.py   # тесты категорий, имён, дубликатов, отмены и dry-run
requirements-dev.txt      # pytest
```

## Как это устроено

- Работа разделена на `plan` (только вычисляет пары «откуда, куда») и `apply` (переносит), поэтому `--dry-run` и реальный запуск используют один и тот же план.
- Свободное имя подбирается с учётом и файлов на диске, и переносов, уже запланированных в этом запуске.
- SHA-256 считается блоками по 1 МБ, так что большие файлы не загружаются в память целиком.
- Каждый запуск дописывается в журнал `.organizer-log.json` в самой папке; журнал обновляется после каждого переноса (через временный файл и замену), поэтому даже прерванный запуск можно откатить; `--undo` берёт последнюю запись, возвращает файлы в обратном порядке и убирает пустые папки снизу вверх.
- При отмене файл возвращается, только если он есть на новом месте и старое имя свободно.
